# dsh-workbuddy-native Spec

> 版本：草案 v1（2026-10-08）。需求来源：会话对齐记录 + 项目记忆。
> 探针结论（P1–P4）已核实并作为本文的事实基础。

## 背景

现有 WorkBuddy 桥接插件（1.4.0）是一台寄生在 `127.0.0.1:37321` 上的 OpenAI 兼容 HTTP 中转站：DSH 通过 pi-ai 以一个 provider 的身份连它，它再转发给 WorkBuddy 上游。这个"位置错了"派生出全部主要缺陷——模型列表靠手写 YAML 补丁与运行时目录脱节（出现过 unknown_model 400）、同一 provider 路由在两个站点间改语义、思考内容在链路上丢失、非流式请求要整段折叠白等、authToken 需要两处手工同步、内嵌网页面板与设置面板双份维护。

另有一次"2.0 原生适配器"尝试，因致命错误被废弃，代码已删，仅文档存留。本插件是**重新开发**，不复用其代码。

宿主能力已探明（2026-10-08，安装版 asar）：
- LLM 适配器可原生注册，模型目录由注册表驱动，热更新有官方机制；
- 模型目录构建每次现场调用且无超时，适配器必须同步返回缓存；
- 工具注册接受裸定义对象，无需导入宿主包（现有插件工具全灭的根因可整根消除）;
- 宿主**不会**为第三方渲染任何登录入口，登录界面必须插件自绘；
- 聊天输入区附近有公开挂载点，简易显示可以落在用户截图指定的位置。

## 目标

把 WorkBuddy 积分计费模型的使用体验收进 DeepSeek Harness 原生形态：无本地 HTTP 服务、无手工维护的模型层、两个站点同时可选、思考过程可见、超限有治理、用量与费用透明。

## 功能需求

### 提供与目录

- **F1 原生模型提供**：模型选择器中出现两个独立分组——WorkBuddy 国内版、WorkBuddy 国际版。分组与模型完全来自上游实时目录（受 UA 门控的合并配置），倍率写入模型显示名；路由器档位（auto/default 及各 `*-model`）不出现。目录变化不需要改任何配置文件、不需要重启。
- **F2 目录刷新**：启动时、每小时、每次登录或站点凭证变化后，后台刷新目录。刷新期间选择器与进行中的请求不受影响；网络慢或失败时选择器立即返回上一次缓存，绝不等待网络。
- **F3 显示名口径统一**：模型倍率只算一处（现价 = 基础倍率 × 生效中的促销折扣），选择器、简易显示、设置面板三处同源渲染，不再出现两套口径。

### 传输与登录

- **F4 双传输**：direct（OAuth 设备码直连，真流式）为默认传输；wbipc（本地 WorkBuddy 桌面端代持鉴权）保留为显式选项，在设置面板一键切换，切换即时生效。wbipc 响应超出尺寸上限时自动分段续写（每段有输出预算，被拒时预算折半；以已收正文为前缀继续，最多 3 段续写），对会话呈现为连续输出，且**每段都是真实计费、逐段过预算闸**；仍触顶则明确报错。请求体超限返回明确报错（提示压缩图片/缩短上下文/切换 direct）。桌面端不在线或协议被上游变更时给出可理解的错误并建议回落 direct。
- **F5 登录与多账号**：设置面板内发起扫码登录；国内/国际两站点各自保存凭证与多账号，切换即时生效。凭证存入宿主凭据保险柜；token 过期自动刷新、401 自动重试一次。旧插件数据目录中的已有账号做一次性只读导入，不回写旧文件。
- **F6 免费额度治理**：免费模型的当日额度耗尽时，自动停止该模型的新请求（拒绝并说明"已达上限，下一次免费在 xx:xx"，时间从促销时段推算），选择器、简易显示、设置面板中该模型变红；提供默认关闭的"耗尽后允许按原价继续"开关。

### 治理与观测

- **F7 预算守卫**：日积分预算按本地日历日计，当日已耗从用量日志重建（日志是唯一真源，计数文件只是缓存）；单次请求预估上限防失控；接近上下文上限时给出预警。超限拒绝时说明原因与调整方式。
- **F8 用量日志**：每次请求记一行精简 JSONL——时间、站点、模型、状态、耗时、token 明细（含缓存命中、思考 token）、积分。**绝不写入对话内容或请求/响应体。** 日志保留期可配置。
- **F9 Agent 工具**：对话内可让 agent 查询余额与今日用量、列出/切换账号、切换传输模式、读取实时价格。零宿主包依赖注册。
- **F10 思考与工具调用**：上游返回的思考内容完整进入思考流（对用户可见）；工具调用按标准协议双向映射；流式逐字输出，不做折叠。

### 界面

- **F11 简易显示**：聊天输入区上方（用户截图同位）提供状态胶囊，悬停展开简易显示，必须包含：① 当前站点（国际/国内）；② 今日已用积分；③ 真实剩余余额（各套餐合计，可手动刷新）；④ 有折扣的模型以绿色加粗显示名字与额度；⑤ 已回原价的模型以红色显示；⑥ 当前模型与倍率。展开层可点击跳转设置面板。跟随系统深浅主题。
- **F12 设置面板**：设置中的"WorkBuddy 桥接"分区为全量控制面：账号（当前账号、凭证到期、扫码登录、多账号切换）、站点徽章、传输开关、预算三项（含调整入口）、实时价格表（绿/红语义与 F3 同源）、每模型缓存命中率与思考 token 占比、今日按模型明细。跟随系统深浅主题。

### 费用验证实验（开发完成后执行）

- **F13** 对用户提出的三个费用断言做实测确认并给出优化方案：① 长推理慢速模型带来额外费用（同输入不同思考档位对比积分）；② 免费额度耗尽后同请求按原价计费（耗尽临界点前后对比）；③ 未命中上游提示缓存的请求额外付费（固定前缀跨时间点重复，逐模型记录命中率）。实验消耗真实积分，**总量封顶 50 积分**，每笔入日志，达到上限即停并汇报。

## 非功能需求

- **N1 只用官方接缝**：仅通过宿主公开的插件接缝实现；某接缝缺失或变更时优雅降级（工具、面板、登录按钮各自独立存活），绝不修改宿主文件。
- **N2 隐私**：对话内容不落盘；凭证不进明文私有文件（宿主保险柜优先）；日志默认不含请求体，写体路径在代码上不存在。
- **N3 与旧版共存**：独立的模型路由名与数据目录；安装、验证、回退全程不触碰旧插件；旧插件退役由用户另行决定。
- **N4 主题跟随**：全部界面色值来自宿主主题令牌，不硬编码。
- **N5 上游礼仪**：UA 版本段可配置，设置面板显示当前取值与"目录来自哪次抓取"；不做任何对抗上游风控的行为。
- **N6 故障降级链**：wbipc 不可用 → 提示并可用 direct；direct 未登录 → 明确引导登录；目录不可达 → 沿用上次缓存并在面板标注抓取时间。

## 不做的事

- 不修改、不移动、不配置旧插件（退役另议）。
- 不为已删除的消费面板维持任何跨插件契约。
- 不做"超限自动换模型"——换模型会打断上游缓存前缀并改变会话语义，只停止并提示。
- 不伪造缓存参数、不对抗风控、不超量试探免费额度（F13 实验除外，已获批封顶）。
- 不做远程暴露：本地服务面（如有）仅回环可用。
- 不承诺 wbipc 协议在桌面端升级后仍然可用（N6 只保证可理解地失败）。
